HOW TO USE / 使用原则

算得清楚，也要知道哪里算不准

工具的价值是帮你把模糊感觉变成可追踪的变量，而不是给一个看起来很精确的答案。

先看公式与口径

每个工具下方都写了计算式、单位与统计口径。同一个「训练容量」在不同口径下含义完全不同，先确认你算的是哪一个。

用趋势校正估算

公式来自群体数据，对个体可能有明显偏差。用晨起体重 7 日均线、围度与同动作表现去修正起始值，比换一个公式更有用。

守住健康边界

工具不评估伤病、疾病或用药情况，也不提供任何非法药物方案。出现疼痛、持续表现下滑或医学问题，请找医生与具备资质的专业人员。
