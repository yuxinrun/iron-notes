这套计划服务的对象很具体：**已经能稳定完成基础动作、每周只有 3 天可训练、希望每个肌群每周都练到的人。** 如果你完全没进过健身房，先按《从零开始增肌》的前两周适应流程走；如果你每周能去 5–6 天，这套计划的容量对你可能偏低。

## 一、计划概览

| 项目 | 内容 |
| --- | --- |
| 每周训练 | 3 天，建议周一／周三／周五 |
| 分化 | 全身训练（A 蹲主导 / B 髋主导 / C 补强） |
| 单次时长 | 55–70 分钟 |
| 器械 | 杠铃、哑铃、常用固定器械 |
| 强度 | 大多数组 RIR 2–3 |
| 适合 | 新手、初级，恢复能力中等 |
| 不适用 | 有未评估的疼痛或伤病、每周只能练 1–2 天、追求专项力量峰值 |

## 三、热身：不要跳过，也不要做成第二场训练

- 5–8 分钟低强度有氧（快走、椭圆机）让体温上来。
- 动态活动度：髋、踝、胸椎、肩胛各 1 分钟。
- 主项递增强度 2–3 组：空杆 × 8 → 约 50% × 5 → 约 70% × 3，然后进入正式组。
- 正式组第一组不要用当天最重重量去「试」。

热身组不计入有效组数。

## 四、进阶规则：双重渐进

1. 每个动作先固定重量，把目标次数区间内所有组都做到上限。
2. 条件全部满足（次数到上限 + RIR ≥ 2 + 动作不变形）时，下次加 2.5–5% 重量；上肢可 1–2 kg。
3. 加重量后次数回落到区间下限是正常的，重新爬升。
4. **前 4 周不加组数**。第 5 周起若恢复良好，给最薄弱的 1–2 个部位各加 1 组。
5. 连续 2 次同重量表现下滑：先查睡眠与热量，再考虑减 1 组或降 5% 重量。

## 五、减量与调整

每 6–8 周安排一次减量周：每个动作减 1 组、重量降约 10%、RIR 提到 4，保留动作模式与频率。出现以下情况时可提前减量：

- 连续两次训练表现明显下滑。
- 睡眠质量持续变差、食欲下降。
- 关节出现新的不适（先停止相关动作并评估，必要时就医）。
- 工作或生活压力突然加大。

## 六、替代动作

| 原动作 | 替代 | 适用情况 |
| --- | --- | --- |
| 杠铃背蹲 | 前蹲 / 腿举 / 高脚杯深蹲 | 踝活动度不足、暂时不想上杠铃 |
| 杠铃划船 | 胸部支撑划船 / 坐姿划船 | 下背容易疲劳 |
| 坐姿哑铃肩推 | 器械推肩 | 肩部稳定尚不足 |
| 悬垂举腿 | 反向卷腹 / 死虫式 | 握力或核心不足 |
| 保加利亚分腿蹲 | 分腿蹲 / 箭步蹲 | 平衡困难 |

替代后请重新建立两周基线，不要直接沿用旧动作的重量。

## 七、常见错误

- 三个训练日连着练，腿部与下背恢复吃紧。
- 每次都换动作，导致无法跨周比较。
- 前两周就把每组做到力竭。
- 只看 A 日主项，忽略 B、C 日的容量贡献。
- 热身组练到力竭，正式组反而掉次数。

## 九、收尾

这套计划没有任何秘密动作。它的价值在于：三个训练日、固定的动作、可比较的记录，以及一套写清楚什么时候加、什么时候减的规则。**训练计划不是用来炫耀复杂的，是用来坚持执行的。** 想要可直接打卡的版本，可打开 [新手一周三练全身增肌](/plans/full-body-3)。
