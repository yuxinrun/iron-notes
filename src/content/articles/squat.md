很多人学深蹲，学的是「膝盖不要超过脚尖」「蹲到平行」「眼睛看前方」这几句口诀。它们不算全错，但都只描述了外观，没解释力是怎么从地面传到杠铃的。

更实用的切入是：**深蹲是一个足底压力管理问题。** 只要重心跑掉，膝盖、髋、腰就会依次代偿。

## 一、动作档案

| 项目 | 内容 |
| --- | --- |
| 中文名 / 英文名 | 杠铃背蹲 / Barbell Back Squat |
| 目标肌群 | 股四头肌、臀大肌 |
| 协同肌群 | 腘绳肌、内收肌、竖脊肌、腹肌、小腿 |
| 器械 | 杠铃、深蹲架、保护杆 |

## 二、起始：先把三个点钉住

1. **杠位**：高杠放在斜方肌上束，低杠放在三角肌后束附近。杠位越高，躯干通常越直立；杠位越低，髋参与更多。不要用颈椎顶住杠铃。
2. **脚掌三点**：大脚趾根、小脚趾根、脚跟同时压地。脚尖略外展，角度以髋部舒适为准，一般 5–20 度。
3. **躯干刚性**：吸气建立腹内压，肋骨下沉，肩胛收紧托住杠铃，目光平视前方略下。

起杠后向后退 1–2 步即可，站位一旦确定，整组不再挪动。

## 三、动作步骤

1. 吸气收紧核心与背阔肌，把杠铃「夹」在背上。
2. **髋与膝同时启动**：不是先屈髋也不是先推膝，而是让两者一起折叠。
3. 下蹲时膝盖沿脚尖方向前移，躯干与小腿大致保持相近倾角，重心落在足中部。
4. 下蹲至髋关节略低于膝关节，或达到个人无痛的最大可控深度。
5. 呼气，脚掌整体蹬地，**髋与肩同步上升**，膝盖保持外展不内扣。
6. 站直但不过度后仰，准备下一次重复。

```

**呼吸**：下蹲前吸气并短暂屏气维持躯干刚性，越过粘滞点后呼气。有血压问题或憋气不适者改为自然呼吸节律，不长时间屏气。

**幅度上限（三条硬标准）**：脚跟不抬离地面、骨盆不出现明显后翻、腰椎保持中立。任何一条失守，就已经超过你当下该蹲的深度。

## 四、常见错误与它真正的成因

| 表现 | 常见成因 | 修正方向 |
| --- | --- | --- |
| 脚跟抬起、重心前移 | 踝背屈不足，或杠位／鞋底不合适 | 穿举重鞋或垫高脚跟，同步练踝灵活性 |
| 膝盖明显内扣 | 臀中肌稳定不足、脚尖外展不够 | 减重，用「把地板向外撑开」的提示，补单侧稳定训练 |
| 起身时臀部先抬、躯干前扑 | 伸膝力量不足或重心偏后 | 减重，强调髋肩同步，补腿举与分腿蹲 |
| 骨盆后翻（俗称 butt wink） | 下蹲超过髋活动度 | 缩小深度，垫高脚跟，做髋与踝活动度训练 |
| 杠铃位置过高压颈椎 | 起杠姿势错误 | 重新调整杠位与肩胛收紧 |
| 下背先累而不是腿先累 | 竖脊肌等长耐力成为限制 | 减少单组次数，增加核心抗伸展训练 |

```

## 五、三种体型差异

- **躯干长、小腿短**：容易更直立，膝前移较多，通常较容易蹲深。
- **股骨长、躯干短**：需要更大躯干前倾才能保持重心，低杠位或垫高脚跟更友好。
- **踝背屈受限**：无论体型，都会表现为深度受限或躯干过度前倾。

所以「标准深蹲姿势」不是一张适用于所有人的照片，而是三条可检查的力学条件。**别把别人的脚位与深度当成你的模板。**

## 六、怎么练：从零到负重

1. **阶段 1**：自重箱式深蹲、高脚杯深蹲，学髋膝同步与足底三点。
2. **阶段 2**：空杆背蹲，拍侧面录像检查路径与骨盆位置。
3. **阶段 3**：加重，3 组 × 6–8 次，RIR 2–3，组间休息 2–3 分钟。
4. **阶段 4**：按双重渐进加次数与重量，同时保留一个单侧动作（保加利亚分腿蹲）补稳定。

较长组间休息对较重负荷与复合动作的力量表现更有利，所以深蹲不必把休息压到 60 秒。时间紧时宁可减少辅助动作，也不要压缩主项休息。

## 七、安全提示

深蹲请设置保护杆，或由有经验的保护者协助。出现膝关节、髋部或腰部持续疼痛、肿胀、活动受限，请停止诱发动作并咨询医生与具备资质的专业人员。本文不提供康复方案。

## 九、收尾

深蹲的技术难点不在「蹲多深」，而在整组里重心有没有跑掉、躯干有没有保持刚性、每一次起落是不是可比较。把这三点固定住，重量才有意义。完整动作档案可查看 [动作图鉴 · 杠铃背蹲](/exercises/back-squat)。
