第一次走进健身房，最容易被两件事劝退：一是器械看起来都像刑具，二是每个人都在告诉你不同的做法。有人说必须练到吐，有人说每天练同一个部位才长得快，还有人递给你一张写满二十个动作的计划表。

先把这些声音关掉。**增肌不是一次性把自己练废，而是一段可重复、可记录、可调整的过程。** 这篇指南只做一件事：让你从今天到第八周，每一步都知道自己在做什么、为什么做、做完怎么判断有没有效。

## 一、先说清楚：你要增长的到底是什么

日常说的「变壮」，混着三件不同的事：肌肉量增加、力量提升、体重上升。它们经常一起发生，但不是同一件事。

- **肌肉量**：肌纤维横截面积变大，是肌肥大（hypertrophy）要讨论的对象，需要以月为单位观察。
- **力量**：你能举起的重量，很大一部分来自神经系统学会更高效地招募肌肉，新手前几周进步快主要是这个原因。
- **体重**：包含水分、胃肠内容物、糖原与脂肪，单日波动可以到 0.5–1 kg。

所以第一天别急着定「一个月长五斤」这种目标。更合理的目标是：**八周后，同一套动作、同样的动作质量下，你能稳定完成更多次数或更重的重量，并且知道自己的周训练量是多少。**

## 二、开始前必须确认的三件事

**1）身体状况。** 持续疼痛、关节肿胀、活动明显受限、运动时胸闷头晕，都不是「练练就好」的信号，先就医。没有这些情况也不代表可以随便加重量，只是说明可以从低强度起步。

**2）每周能稳定拿出几天。** 这比「哪种分化最科学」重要得多。一周两练坚持一年，胜过一周五练坚持三周。诚实评估：把通勤、加班、家庭安排都算进去，还剩几个 45–60 分钟的整块时间？

**3）可用器械。** 商用健身房、公司健身房、家里一对可调哑铃，对应完全不同的动作库。器械少不是障碍，只是需要不同的安排。

想清楚这三个答案，再往下选计划。**没有任何一套计划适合所有人**，训练经验、时间、恢复能力与身体状况都会改变答案。

## 三、三个条件，缺一个都不成立

```iron-figure
{"name":"hypertrophy-mechanism","caption":"肌肥大的三个必要条件：训练刺激、营养供给、恢复能力"}
```

新手最容易把全部注意力放在第一格：动作要不要换、要不要加组、要不要练到力竭。但训练只是发出信号，身体得有材料、有时间才能响应。一个很实用的判断法是：当进步停住时，按顺序检查「记录有没有断 → 睡眠与热量有没有变 → 训练量要不要调」，而不是第一时间换计划。

## 四、第 1–2 周：只做四件事

前两周千万别追求酸痛。你的任务是收集信息，不是证明决心。

1. **学会 4 个基础动作模式**：蹲（腿举或高脚杯深蹲）、髋铰链（罗马尼亚硬拉或臀桥）、水平推（器械推胸或俯卧撑）、拉（高位下拉或坐姿划船）。
2. **每个动作只用能完全控制的重量**，做 2 组 × 10–12 次，结束时感觉「还能再做 4 次左右」就停。
3. **写训练日志**：日期、动作、重量、次数、组数、这一组结束时大概还能再做几次。手写本子就够，重要的是不要靠记忆。
4. **固定训练日**，比如周一、周三、周五。把训练当成日程，而不是等有空。

这两周你可能会觉得「太轻了，没感觉」。这正是对的。动作学习需要低干扰环境，把重量压住，才有余量去注意脚跟有没有离地、肩胛有没有收紧、下放有没有控制。

## 五、第 3–8 周：一套可以直接照做的周计划

三练全身是新手最稳的起点：动作少、频率够、每次都能练到全身，且隔天恢复。下面这张表是**模板**，不是处方。

| 训练日 | 动作 | 组数 × 次数 | 休息 | 强度 |
| --- | --- | --- | --- | --- |
| A（蹲主导） | 坐姿腿举 | 2–3 × 10–12 | 90 秒 | 留 3 RIR |
| | 器械推胸 | 2–3 × 10–12 | 90 秒 | 留 3 RIR |
| | 高位下拉 | 2–3 × 10–12 | 90 秒 | 留 3 RIR |
| | 平板支撑 | 2 × 20–30 秒 | 45 秒 | 保持中立位 |
| B（髋主导） | 罗马尼亚硬拉（轻） | 2–3 × 10 | 90 秒 | 留 3 RIR |
| | 坐姿划船 | 2–3 × 10–12 | 90 秒 | 留 3 RIR |
| | 哑铃侧平举 | 2 × 12–15 | 60 秒 | 留 2–3 RIR |
| | 绳索三头下压 | 2 × 12–15 | 60 秒 | 留 2–3 RIR |
| C（补强） | 高脚杯深蹲 | 2–3 × 10 | 90 秒 | 留 3 RIR |
| | 上斜哑铃卧推 | 2–3 × 10–12 | 90 秒 | 留 3 RIR |
| | 坐姿腿弯举 | 2 × 12–15 | 60 秒 | 留 2–3 RIR |
| | 死虫式 | 2 × 每侧 8 | 45 秒 | 控制不塌腰 |

**RIR（Repetitions in Reserve）** 指这组结束时你估计还能再做的次数。留 3 RIR，就是「大概还能再做 3 次」。新手对这个数字的估计一开始不准，没关系，它更像一个需要练习的技能，而不是仪器。

**进阶规则只有一条**：同一个动作，当所有组都做到次数区间上限、动作不变形、且 RIR 仍然 ≥ 3，下一次训练加约 2.5–5% 重量（上肢可以只加 1–2 kg）。加完之后次数大概率会掉回区间下限，那就再慢慢把次数爬上来。这套「先加次数、再加重量」叫双重渐进，是新手最不容易受伤也最容易坚持的进阶方式。

```iron-figure
{"name":"overload-ladder","caption":"双重渐进法：先在同重量下把次数做到上限，再加重量重新爬升"}
```

**前四周不要加组数。** 恢复能力还没建立起来时，加组数会先让下一次训练质量下降。第五周起如果每次都练得完整、睡眠正常、没有持续关节不适，可以给最想发展的 1–2 个部位各加 1 组。

## 六、吃：先抓住两个数字，别一上来算到小数点

新手在饮食上最常犯的错，是先买补剂、后算总热量。顺序应该反过来。

**第一，热量大致够不够。** 用 Mifflin-St Jeor 公式估出基础代谢，再乘活动系数得到每日总消耗估算，然后加一个温和盈余。这个公式是群体预测式，个体偏差很常见，所以它的正确用法是「给一个起点」，再用两周体重趋势校准。

**第二，全天蛋白质总量。** 系统综述提示，运动人群的蛋白需求高于一般推荐量，蛋白质补充在抗阻训练基础上带来小幅额外增益，在总摄入约 1.6 g/kg/日 之后边际收益趋于平缓。请把它理解为**研究中观察到的平均拐点**，不是人人必须达标的硬指标。

一个 70 kg 的新手，先把每天蛋白质落在约 100–140 g 这个区间，分到 3–4 餐，每餐有一份蛋、奶、鱼虾、禽肉、瘦肉或豆制品。做到这一点，比研究「训练后 30 分钟窗口」有用得多。

```iron-note
{"type":"warning","title":"别把估算当处方","text":"热量公式、蛋白质区间都是群体层面的起点。体重两周没变化，说明估算与实际消耗有偏差，应调整摄入或活动量，而不是认定公式错了或者自己体质特殊。"}
```

## 七、恢复：把睡眠写进计划，而不是留给运气

一次训练后，表现会短暂下降，然后随恢复回到甚至略高于原来的水平。这个「先降后升」的周期，是安排训练频率的底层逻辑。

```iron-figure
{"name":"training-cycle","caption":"训练刺激—疲劳—恢复周期：下一次训练应安排在表现恢复之后"}
```

实操上三件事就够：三练日尽量隔开、每晚尽量固定睡眠时段、连续两次训练表现都下滑时先减一组而不是硬顶。睡眠不足与后续力量表现下降相关，但把它直接写成「睡少了就完全不长肌肉」是过度推论——证据更多支持的是短期表现与恢复感受，长期肥大的因果链还没有那么确定。

## 八、第 8 周复盘：怎么判断有没有效

翻训练日志，回答四个问题：

1. **主要动作有没有进步？** 同一重量下次数增加，或同次数下重量增加，都算。
2. **每周训练有没有按计划完成？** 完成率低于 80%，问题在日程不在计划。
3. **体重 7 日均线怎么走？** 一直持平且力量也不涨，先查热量；快速上升且腰围同步涨，盈余偏大。
4. **有没有疼痛？** 出现持续关节痛，先调整动作与负荷，必要时就医。

## 九、新手最常见的六个错误

- **每周换计划**：刺激还没累积就重新开始，等于永远在第一周。
- **用酸痛当成绩单**：延迟性酸痛更多反映新动作与新容量的冲击，不是肥大的必要条件。
- **每组都练到力竭**：非力竭训练在多数肥大指标上并不逊色，且疲劳成本更低。
- **只记重量不记次数与 RIR**：少了这两个数字，你无法判断当天的状态。
- **靠补剂弥补饮食**：补剂位于优先级的最末端。
- **忽略动作质量去加重量**：一个动作做不标准，加重量只是在把错误练得更牢。

## 十一、最后一句

增肌最怕的不是训练太少，而是每次都在重新开始。你现在需要的不是更聪明的计划，是一份能连续写满八周的训练日志。
